StuMarket or Student Marketplace

A responsive landing page concept for a student marketplace to buy and sell school supplies, gadgets, and other student essentials.

## Features

- Hero section with a call to action
- Benefits section highlighting affordability, selling, and ease of use
- Responsive navigation menu
- Search bar and “Live Drops” section
